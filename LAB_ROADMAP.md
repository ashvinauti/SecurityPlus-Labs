# Security+ SY0-701 Lab Roadmap

This roadmap turns the repository from a study-note collection into a hands-on portfolio.

## Lab Standard

Every lab should include:

1. Scenario
2. Security+ domain/objective
3. Learning objectives
4. Prerequisites
5. Safe lab boundaries
6. Step-by-step tasks
7. Evidence to capture
8. Verification questions
9. Cleanup
10. Portfolio summary

## Recommended Build Order

### Domain 1 — Threats, Vulnerabilities, and Mitigations
- [x] Threat modeling
- [x] Vulnerability assessment and prioritization
- [ ] Social engineering recognition exercise
- [ ] Secure configuration review
- [ ] Vulnerability remediation validation

### Domain 2 — Security Architecture
- [x] Network segmentation design
- [ ] Zero Trust policy design

- [ ] High availability and resilience

### Domain 3 — Implementation
- [x] TLS certificate setup and validation
- [ ] IAM and RBAC implementation

### Domain 4 — Security Operations

- [ ] Incident response simulation
- [ ] File integrity monitoring
- [ ] Backup and restore verification
- [ ] Basic SIEM alert triage

### Domain 5 — Security Program Management and Oversight
- [x] Risk assessment
- [ ] Security policy review
- [ ] Third-party risk assessment
- [ ] Business impact analysis
- [ ] Compliance evidence checklist

## Portfolio Evidence

For each completed lab, save sanitized evidence under a structure such as:

```text
evidence/
  screenshots/
  outputs/
  reports/
```

Never commit passwords, API keys, private keys, tokens, personal data, or confidential organizational information.
